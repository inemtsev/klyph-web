Each step adds **one** new thing and ends with your game doing something new. Run it after every step. Seeing it work is half the fun.

{{< kip tip "How to do the Quest" >}}
- **One step at a time.** Do a step, run the game, press **I did it!**, then take a break if you want.
- **Copy-paste is fine.** Every code box has a **Copy** button. Typing it yourself helps it stick, though.
- **Stuck?** Each few steps has a **checkpoint**: the full code up to there.
- **Underlined words** like {{< term "sprite" >}} open a short explanation. Hover to peek.
{{< /kip >}}
